We are looking for **3–5 volunteers** to take the Loop Practitioner exam v0.1 and report friction.

**Exam:** https://github.com/KanakMalpani/Loop-Engineering/blob/main/education/practitioner/exam-v0.1.md

```bash
pip install "le-loopforge>=0.2.0" "le-loopctl>=0.1.0"
```

1. Completed written section answers (DM maintainer or attach gist)
2. Hands-on capstone: `loopforge intent` → `loopctl validate` → LES JSON
3. Brief feedback: what was unclear, what took longest
